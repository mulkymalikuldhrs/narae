# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-20

### Added
- Initial release of NARAÈ website
- Modern glassmorphism design system
- Responsive product catalog with 3 variants
- Direct links to Shopee marketplace
- WhatsApp inquiry integration
- Premium animations and hover effects
- Mobile-first responsive design

### Design Features
- Glassmorphism UI components
- Custom color palette (Cream, Gold, Charcoal, Lavender)
- Typography system with Cormorant Garamond & Inter fonts
- Parallax mouse-tracking effects
- Smooth scroll animations
- Premium card hover states

### Technical
- Next.js 16 with App Router
- React 19
- Tailwind CSS 4
- Static site generation
- Optimized image assets
- CSS-only animations

## [0.9.0] - 2026-02-20

### Changed
- Simplified from full e-commerce to catalog-only
- Removed shopping cart functionality
- Removed checkout system
- Removed Zustand state management
- Streamlined user flow to marketplace redirect

### Removed
- Cart drawer component
- Checkout modal
- Order management system
- Admin panel
- Zustand store dependencies

## [0.5.0] - 2026-02-19

### Added
- Project initialization
- Business plan documentation (NARAE.md)
- Website specification (SPEC.md)
- Brand guidelines and assets
- Component architecture
