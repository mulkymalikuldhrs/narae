## 🇬🇧 English

### 🎯 About NARAÈ

NARAÈ is a premium bath soak aromatherapy brand with a **clean neutral luxury** concept. This website serves as a product catalog directing customers to marketplace (Shopee) for purchase. Crafted with care for those who seek tranquility and self-care.

> "Tenangkan pikiran, manjakan diri."  
> *Calm your mind, pamper yourself*

### ✨ Key Features

- 🌿 **Modern Glassmorphism Design** — Premium UI with frosted glass effects
- 📱 **Responsive Layout** — Mobile-first, works on all devices
- ⚡ **Fast Loading** — Static site generation with Next.js
- 🔍 **SEO Optimized** — Meta tags, Open Graph, semantic HTML
- 🛒 **Direct Marketplace Integration** — Buy buttons to Shopee & WhatsApp
- 💎 **Zero Backend** — 100% static, no database needed

## 🇨🇳 中文

### 🎯 关于 NARAÈ

NARAÈ 是一个优质浴盐芳香疗法品牌，采用**清洁中性奢华**理念。本网站作为产品目录，引导客户到市场（Shopee）购买。为追求宁静和自我护理的人精心打造。
